FavNC Base64 API

Convert text ↔ Base64 using simple requests:

GET https://favnc.pages.dev/api/base64?txt=hello
GET https://favnc.pages.dev/api/base64?base=aGVsbG8=

JavaScript Example

fetch("/api/base64?txt=hello")
.then(r=>r.json())
.then(d=>console.log(d.base))

Python Example

import requests
r=requests.get("https://favnc.pages.dev/api/base64",params={"txt":"hello"})
print(r.json()["base"])

HTML Usage

<code>Encoded: aGVsbG8=</code>
