Discord timestamp basics

Syntax in Discord:

<t:UNIX:STYLE>

Styles:

t  → short time          21:37
T  → long time           21:37:42
d  → short date          11/29/2025
D  → long date           November 29, 2025
f  → date + time         November 29, 2025 21:37
F  → full                Saturday, November 29, 2025 21:37
R  → relative            in 5 minutes / 2 hours ago

Paste the generated code directly into messages, embeds or bot responses.

Source Code & API idea

Fav_DTS builds the code in the browser. A simple API could look like:

GET https://favnc.pages.dev/api/time-stamp?date=2025-11-29&time=21:37&style=R

Example JSON response:

{
  "code": "<t:1764442620:R>",
  "unix": 1764442620,
  "style": "R"
}

JS core (front-end)

function buildTimestamp(dateStr,timeStr,style){
  const d=new Date(dateStr+"T"+timeStr);
  const ts=Math.floor(d.getTime()/1000);
  return "<t:"+ts+":"+(style||"R")+">";
}

Python example

from datetime import datetime, timezone

def fav_dts(date_str, time_str, style="R"):
    dt = datetime.fromisoformat(date_str + "T" + time_str)
    ts = int(dt.replace(tzinfo=timezone.utc).timestamp())
    return f"<t:{ts}:{style}>"

Cloudflare Worker sketch for /api/time-stamp

export default {
  async fetch(req) {
    const url = new URL(req.url);
    const date = url.searchParams.get("date");
    const time = url.searchParams.get("time");
    const style = url.searchParams.get("style") || "R";
    if (!date || !time) {
      return new Response(JSON.stringify({error:"date and time required"}), {
        status:400,
        headers: {"content-type":"application/json"}
      });
    }
    const ts = Math.floor(new Date(date+"T"+time).getTime()/1000);
    const code = `<t:${ts}:${style}>`;
    return new Response(JSON.stringify({code, unix:ts, style}), {
      headers: {"content-type":"application/json"}
    });
  }
};
