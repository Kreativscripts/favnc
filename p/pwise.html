Pennywise Scanner V2

Pennywise Scanner V2 is an AI-powered retail security camera system designed for crowded store environments. It detects weapon-shaped threats, flags suspicious visuals, and securely records evidence with overlays and timestamps.

Features

  • Weapon shape detection (knife / gun silhouettes)
  • Suspicious visual flagging (unclear outlines, prints)
  • False-positive reduction (metal-only objects ignored)
  • Automatic 5-second video recording
  • Secure configuration via .env

Detection Logic

State Trigger Action
DETECTED Knife or gun above confidence threshold 5s video, red bounding box, saved to /Detected
SUSPICIOUS Partial outline or weird pattern Still images, yellow box, saved to /Suspicious
IGNORED Keys, phones, metal-only objects No action

.env Configuration

Only one value is stored:

AI_KEY=your_ai_key_here

Privacy & Safety

  • No identity tracking
