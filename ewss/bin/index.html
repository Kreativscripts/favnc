📋 Build Directory Overview

This directory contains the compiled executables and build artifacts for WSS Exam Them v0.0.1. The main applications are located in the dist/ folder.

⚠️ Important: The build/ folder contains intermediate build files and should not be distributed. Only the files in dist/ are needed for end users.

Build Commands Used:

# Teacher Application
pyinstaller --onefile --noconsole --icon="EWSS.png" --name="WSS Exam Them - TEACHER" --add-data "dashboard.html;." teacher_app.py

# Student Application
pyinstaller --onefile --icon="EWSS.png" --name="WSS Exam Them - STUDENT" student_app.py
