WSS Exam Them

Real-Time Exam Monitoring System

A secure LAN-based monitoring solution for educational environments. Teachers can monitor student activity in real-time while students remain focused on approved exam applications. No internet required, no invasive tracking.

📦 Ready-to-Use Applications

Both applications are compiled as standalone EXE files. No installation required.

Teacher: ~8MB | Student: ~7MB

🚀 How It Works

1

Teacher Launches Server

Run the Teacher application. It starts a local web server with a real-time dashboard. The app displays connection URLs for students.

2

Students Connect

Students run the Student app, enter the teacher's IP address, and select their exam application. The app launches the exam and begins monitoring.

3

Real-time Monitoring

Teacher dashboard shows live student activity, including exam start/stop times and heartbeat status. All events are logged for review.

4

Complete Session

When exams are complete, teacher can clear logs or export data. Students can exit monitoring, sending a final "stopped" event.
